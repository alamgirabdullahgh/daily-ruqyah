# সমপর্যায়ের আয়াত যোগ করতে হবে (ধাপ ২-এ সূচিতে বসবে)
যোগ: ঘটনা ২২৫ ← ১৮:২৯ (জাহান্নামীদের পানীয়ের দৃশ্য; ১৮:৫২-৫৩ ইতোমধ্যে এই ঘটনায়)
যোগ: ঘটনা ১১৭ ← ১৩:১৪ (দৃষ্টান্ত: পানির দিকে দু'হাত বাড়ানো ব্যক্তি; সূরা ১৩ যাচাইয়ে ধরা পড়েছে)
যোগ: ঘটনা ১১৭ ← ২২:৩১ (শিরকের দৃষ্টান্ত: আকাশ থেকে পড়া ব্যক্তি)
যোগ: ঘটনা ৫৩ ← ২৮:৫৯ (জনপদ রসূল পাঠানোর পরই ধ্বংস; ২৮:৫৮ ও ১৭:১৫-২১ একই গুচ্ছে আছে)
যোগ: ঘটনা ৫৩ ← ৩০:৪২ (পৃথিবী ঘুরে পূর্ববর্তীদের পরিণাম দেখো)
যোগ: ঘটনা ৫৩ ← ৪২:১৩ (নূহ, ইব্রাহীম, মূসা, ঈসাকে একই দ্বীনের আদেশ)
যোগ: ঘটনা ৫৩ ← ৪৬:৩৫ (উচ্চসাহসী পয়গম্বরগণের সবর)
যোগ: ঘটনা ৫৩ ← ৫১:৫৯ (জালেমদের প্রাপ্য অতীত সহচরদের মতো)
যোগ: ঘটনা ৩২ ← ৫৪:২২ (আদ-কাহিনীর পর ধুয়া: কোরআন সহজ করা হয়েছে; ৫৪:১৮-২১ এই ঘটনায়)
যোগ: ঘটনা ৫০ ← ৫৪:৪০ (লূত-কাহিনীর পর ধুয়া; ৫৪:৩৩-৩৯ এই ঘটনায়)
যোগ: ঘটনা ৫৩ ← ৫৪:৫১ (তোমাদের সমমনাদের ধ্বংস করা হয়েছে)
যোগ: ঘটনা ১৬৩ ← ৫৭:১৬ (পূর্ব কিতাবধারীদের অন্তর কঠিন হয়ে যাওয়া)
যোগ: ঘটনা ১১৭ ← ৫৭:২০ (দুনিয়ার জীবনের উপমা: বৃষ্টি ও ফসল)
যোগ: ঘটনা ১৫৮ ← ৬১:৪ (আল্লাহর পথে সারিবদ্ধ লড়াই)
