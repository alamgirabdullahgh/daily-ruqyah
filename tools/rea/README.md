# REA — Reverse Engineer Anything

ওপেন-সোর্স রিভার্স-ইঞ্জিনিয়ারিং MCP টুল: বাইনারি, অ্যাপ (Electron/Android/.NET/JS), ওয়েবসাইট, WebAssembly, ফার্মওয়্যার ও প্যাকেট ক্যাপচার বিশ্লেষণ করে AI এজেন্টকে দেয়। Hopper, Ghidra ও IDA ইঞ্জিন সমর্থিত।

- সংস্করণ: ৬.১০.১ (`REA_VERSION` দিয়ে বদলানো যায়)
- Node.js: ২২.২৩.৪+ (২২.x) / ২৪.২২.১+ (২৪.x) / ২৬.১২.১+

## ব্যবহার
```bash
tools/rea/rea.sh --version   # চালু আছে কি না দেখুন
tools/rea/rea.sh setup       # Claude Code/অন্য MCP ক্লায়েন্টে যুক্ত করার ধাপ
```
ডাইরেক্ট: `npx rea-agents setup`, বা `npm install --global rea-agents`। মূল কোড এই রিপোতে রাখা হয়নি (প্রায় ১৭০ MB); সবসময় অফিসিয়াল রিপো/npm থেকে নামান।
